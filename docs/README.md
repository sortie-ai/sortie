# Sortie documentation

These pages are for working on Sortie itself. To install, configure, and run Sortie, read the [user documentation](https://docs.sortie-ai.com) instead. New to the codebase? Start with the architecture index; it gives the system at a glance and routes each task to the one section it needs. Come back to the reference when you need exact `WORKFLOW.md` syntax, to the adapter pages when you add or change an integration, and to the decisions when you want to know why Sortie is built the way it is.
